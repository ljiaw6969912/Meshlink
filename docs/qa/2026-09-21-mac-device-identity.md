# 0.1.13：按 MAC 复用设备身份

- 使用 Windows 原生接口读取物理以太网/Wi-Fi 网卡的永久 MAC，排除 Meshlink、Wintun、代理隧道等虚拟网卡；选择不依赖网卡顺序、连接状态或接口编号。
- 相同 MAC 使用有效接入链接和接入码重新接入时，复用登记的 NodeID、虚拟 IP、路由与创建时间，更新名称和证书；旧证书指纹失效。被禁用、删除的设备以及服务器本机节点不能通过此路径重新注册。
- 本地已有有效身份时，修改名称只更新显示名称，保留证书和 IP；控制连接认证通过后同步名称，并广播给支持该功能的客户端。
- 管理员设置的名称不会被客户端重连时未改动的旧名称覆盖；客户端主动修改名称后则同步新名称。
- MAC 只用于识别记录，不替代接入码或证书认证。没有可用 MAC 时保留原接入逻辑，不以空 MAC 合并设备。
- 旧设备通过证书认证后补登记 MAC。历史记录没有 MAC，不能根据相似名称推断、合并或恢复更早的地址；多个历史身份报告相同 MAC 时明确拒绝冲突，避免静默覆盖身份。
- 先升级服务器，再升级客户端。旧客户端仍能连接新服务器；新客户端向旧服务器接入时，仅在明确的新增字段解析拒绝后重试旧格式，旧服务器不支持 MAC 去重。名称广播按能力协商，旧客户端不会收到不认识的字段。
- 增减物理网卡可能改变选中的 MAC；已登记身份的 MAC 不因重连时的网卡选择变化而覆盖。非 Windows 平台暂不自动发现 MAC。

验证包含 MAC 格式归一化、物理网卡筛选、同 MAC 改名/新目录接入保留地址、不同 MAC 地址隔离、接入码校验、禁用保护、原证书恢复、管理员名称保留、旧服务器接入兼容、认证后补登记以及名称广播不撤销现有直连会话。
