# Meshlink 0.1.8 桌面视觉更新

界面采用深蓝侧栏、浅色工作区、蓝色主要操作、卡片状态区和设备行。服务器/客户端面板继续互斥；长连接信息可在侧栏滚动查看。设备列表显示名称、虚拟地址、真实路径及延迟，概况保留简短摘要，完整原始信息可通过“连接详情”打开。重命名、禁用、移除在顶部“设备”菜单及设备列表右键菜单；诊断在顶部“诊断”菜单。

按钮保留 Windows 原生控件，仅替换绘制。键盘焦点、禁用状态、按下反馈和点击事件保留。Walk 在 WM_DESTROY 时恢复原 WndProc，因此绘制状态及 subclass 在 Disposing 事件释放；窗口销毁回归检查确认状态数从 0 到 11 再回到 0。

验证：

- `go test ./...` 通过；最后的界面调整后再次执行 `go test ./cmd/mesh-desktop -count=1` 和 `go vet ./cmd/mesh-desktop` 通过。
- 原生窗口测试验证服务器/客户端字段恢复、面板互斥、BM_CLICK 模式切换及标题同步。
- 144 DPI 下默认尺寸为 1120×690 逻辑像素，邀请区域有固定高度，长表单可滚动。
- 真实服务器模式预览截图检查了侧栏、按钮、卡片、设备选择及概况布局。客户端模式的控件树验证字段、模式和状态；自动化输入受到系统 GetCursorPos 访问限制，实际点击路由通过原生控件测试验证。
- 尚未进行多显示器 DPI 切换或 Windows 高对比度主题专项验证。

发布仍使用固定 `release/meshlink` 和 `release/meshlink-无配置.zip`，由发布脚本停止服务、校验运行数据、更新并恢复原服务。
