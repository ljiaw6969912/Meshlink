# Meshlink 产品改造需求追踪矩阵

本文档是 Meshlink 产品改造 Task 0 的需求基线。范围来自 `PRODUCT_TRANSFORMATION_PLAN.zh-CN.md` 第 3-15 章，并映射到 `docs/superpowers/plans/2026-07-07-product-transformation.md` 中的 Task 1-11。

Task 0 只冻结需求、阶段边界和验收口径，不实现功能代码。矩阵中的功能要求进入对应 Task 执行；被排除的能力会写明原因，并由 Task 11 在发布说明、风险清单或验收材料中保持可见。

## Task 映射口径

| Task | 名称 | 需求承接范围 |
| --- | --- | --- |
| Task 1 | 巩固当前自托管远程桌面闭环 | 四入口首页、自托管服务器/客户端主流程、节点列表、RDP、普通用户诊断和高级设置收纳 |
| Task 2 | 设备管理、安全边界与吊销能力 | 设备禁用、移除、重命名、证书拒绝列表、审计、路由安全校验、长期邀请码额度 |
| Task 3 | 自建中继部署向导 | SSH 自动部署公网 Hub、远程健康检查、升级、重启、回滚和自建中继运维手册 |
| Task 4 | 官方 Hub MVP 控制面与基础 Relay | 账号、网络、设备绑定、邀请、在线状态、基础 Relay、连接元数据、封禁和吊销入口 |
| Task 5 | 官方 Hub 风控、合规与成本控制 | 技术边界、限速、额度、异常行为检测、协议草案、隐私政策草案、投诉和封禁流程 |
| Task 6 | P2P 控制面协议与局域网/公网直连 | 候选地址、连接协商、路径状态机、LAN direct、公网 direct、Relay 自动回退 |
| Task 7 | NAT 探测、UDP/QUIC 打洞与多路径演进 | NAT 类型探测、UDP/QUIC 选型、打洞状态机、连接质量评分、多路径和热切换 |
| Task 8 | 连接状态可视化与诊断中心 | 连接方式字段、设备列表状态、P2P/Relay 诊断、一键诊断报告、中继流量提醒 |
| Task 9 | 套餐、额度与商业化闭环 | 套餐模型、额度执行、支付订阅适配、客户端套餐提示 |
| Task 10 | 团队与企业能力 | 组织成员、RBAC、设备分组、审计查询、批量部署、企业私有化授权 |
| Task 11 | QA、发布、运维与增长指标 | E2E 矩阵、性能成本基准、发布流水线、监控告警、事故响应、北极星指标看板 |
