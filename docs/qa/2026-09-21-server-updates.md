# 0.1.11 从当前服务器更新

## 行为

- 默认地址由当前网络的服务器地址和连接端口生成：`https://服务器:连接端口/updates`。地址输入框保留 HTTPS 和路径。手动地址只对对应服务器生效，切换网络后重新跟随服务器。
- 使用已有网络 CA 和设备证书验证当前服务器；不向手动指定的其他服务器发送设备证书，不跟随下载重定向。
- 协调服务器在现有 TLS 端口提供经过客户端证书验证的更新接口；独立 1263 服务继续提供旧客户端兼容入口。两者只公开清单、健康检查与当前包下载，不提供运行目录文件访问。
- “立即更新并重启”每次重新检查最新清单，后台下载和校验完整包。关闭更新窗口会取消下载，避免稍后突然重启。
- 固定无配置包内包含逐文件 SHA256/大小清单以及诊断脚本；发布清单的版本 URL 映射固定压缩包，不创建额外版本目录或压缩包。
- 安装器等待桌面退出，停止同一安装目录的全部相关服务与进程，覆盖清单白名单文件，保留配置、证书、邀请码和运行状态。失败回滚；成功恢复原服务状态并启动新版桌面，核对版本及服务状态后一次性提示“更新成功”。
