# 用户协议关键条款草案

> 草案：本文件仅用于产品、工程和运营准备。律师审核前不得作为法律意见、正式用户协议或商业上线承诺使用。

## 服务说明

官方 Hub 提供账号、网络、设备、邀请、审计、Relay session 控制面和受控 Relay 能力。Relay 用于同一官方网络内已授权设备之间的会话级连接，不保证作为公网访问服务、代理服务、固定出口或长期在线中继。

官方 Hub 不提供匿名代理、公网出口、全隧道、HTTP CONNECT、SOCKS、公开转发节点、长期匿名中继或监管规避用途。用户不得将服务用于转售带宽、隐藏来源、绕过监管或绕过第三方平台访问限制。

## 账号和设备责任

用户应保护账号、设备、邀请链接、邀请码和本地凭证安全。用户应只邀请其有权管理或授权的设备加入官方网络。发现账号、设备或邀请被滥用时，应及时吊销设备、撤销邀请或联系支持。

官方 Hub 不主动查看远程桌面内容、文件内容、剪贴板内容，只记录账号安全、滥用处理、计费/额度、客服排查和合规响应所需最小元数据。用户不得要求官方 Hub 作为内容托管、内容审查代理或通用网络转发服务。

## 额度、限制和风控

新账号默认适用低额度策略。官方 Hub 可以按账号状态、Relay byte quota、active Relay session 数、每日 Relay session 创建次数、邀请失败、投诉、执法请求和安全判断限制、冻结或封禁账号。

Quota 超限时，服务应返回可理解的额度错误，而不是伪装成网络故障。Frozen 或 banned 账号不能创建网络、创建邀请、加入设备、发送 heartbeat、创建或激活 Relay session。

## 暂停和终止

官方 Hub 可以对违反可接受使用政策、存在安全风险、收到可信投诉或合法请求的账号采取冻结、封禁、设备吊销、邀请撤销、Relay session 终止和保留审计记录等措施。申诉、解封和执法协助流程应按单独流程草案执行。
