# 隐私政策与最小元数据原则草案

> 草案：本文件仅用于产品、工程和运营准备。律师审核前不得作为法律意见、正式隐私政策或商业上线承诺使用。

## 核心原则

官方 Hub 的设计目标是最小化中心化控制面需要处理的数据。官方 Hub 不主动查看远程桌面内容、文件内容、剪贴板内容，只记录账号安全、滥用处理、计费/额度、客服排查和合规响应所需最小元数据。

官方 Hub 不提供匿名代理、公网出口、全隧道、HTTP CONNECT、SOCKS、公开转发节点、长期匿名中继或监管规避用途。Relay 仅在同一官方网络内为已授权设备对提供会话级中继，不作为通用互联网出口。

## 可能记录的最小元数据

- 账号：账号 ID、邮箱、显示名称、创建时间、账号状态、策略名称、冻结或封禁原因。
- 网络与设备：网络 ID、设备 ID、设备名称、设备状态、加入时间、最后 heartbeat 时间、吊销状态、可选指纹和连接地址。
- 邀请：邀请 ID、所属账号和网络、有效期、使用次数、失败次数、最大失败次数、撤销状态；不记录 invite code 明文，不在审计或风控事件中输出 invite token。
- Relay：session ID、账号 ID、网络 ID、源/目标设备 ID、状态、创建/开始/结束时间、过期时间、Relay byte 计数、关闭错误摘要；不记录 join token 明文。
- 审计与风控：事件类型、时间、账号/网络/设备 ID、原因和经敏感字段过滤后的 metadata。

## 不应记录的数据

- 远程桌面画面、键盘鼠标输入内容、文件内容、文件名清单、剪贴板内容、聊天内容或业务系统内容。
- 私钥、证书私钥 PEM、invite code 明文、invite token 明文、join token 明文、用户密码、长期访问令牌。
- 与安全、额度、客服排查和合规响应无关的持续流量内容或完整包内容。

## 访问与用途

最小元数据仅用于账号安全、滥用处理、额度计算、计费准备、客服排查、系统可靠性和合规响应。内部访问应遵循最小权限、可审计、按需访问原则；商业上线前需要补充权限审批、数据导出、删除请求和地区化合规流程。
