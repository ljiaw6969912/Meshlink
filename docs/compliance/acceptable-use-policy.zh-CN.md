# 可接受使用政策草案

> 草案：本文件仅用于产品、工程和运营准备。律师审核前不得作为法律意见、正式条款或商业上线承诺使用。

## 服务定位

官方 Hub 只用于帮助同一官方网络内已授权设备建立受控连接、记录账号安全与额度所需的最小元数据，并支持滥用处理和客服排查。

官方 Hub 不提供匿名代理、公网出口、全隧道、HTTP CONNECT、SOCKS、公开转发节点、长期匿名中继或监管规避用途。Relay 只能服务同一官方网络内已授权设备对，不得被包装成公网流量出口、绕过访问控制的跳板或第三方转发服务。

## 禁止行为

- 使用官方 Hub 或 Relay 规避法律、监管、制裁、平台风控或网络访问控制。
- 将 Relay 用作匿名代理、公网出口、全隧道、HTTP CONNECT、SOCKS、公开转发节点、长期匿名中继或批量流量转售服务。
- 未经授权访问、扫描、攻击、入侵、干扰或破坏任何账号、设备、网络、系统或服务。
- 传播恶意软件、钓鱼内容、垃圾信息、凭证窃取工具或其他明显滥用内容。
- 通过自动化注册、邀请码枚举、错误邀请码高频尝试、异常 Relay 创建频率或规避额度策略来滥用官方 Hub。
- 上传、存储、转发或处理违法内容，或利用远程控制能力侵犯他人隐私和财产权。

## 执行措施

官方 Hub 可以基于账号状态、设备吊销、邀请失败、Relay 用量、Relay session 创建频率、投诉、执法请求或平台安全判断，采取提醒、限制额度、冻结、封禁、吊销设备、撤销邀请、终止 Relay session、保留审计记录等措施。

单设备吊销只影响该设备；同账号其他未吊销设备在账号仍为 active 且符合策略额度时可继续使用。账号 frozen 或 banned 时，创建网络、创建邀请、设备加入、heartbeat、Relay session 创建和 Relay 激活会被拒绝。

## 数据边界

官方 Hub 不主动查看远程桌面内容、文件内容、剪贴板内容，只记录账号安全、滥用处理、计费/额度、客服排查和合规响应所需最小元数据。不得把私钥、invite token、invite code、join token 或明文凭证写入日志、审计、风控事件或客服记录。
