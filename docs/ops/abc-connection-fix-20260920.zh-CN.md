# A 协调、B/C 直连联调

本文记录本轮早期排查过程。当前服务器兼节点、统一连接按钮与无配置 ZIP 约定以 `simple-mesh-release-20260920.zh-CN.md` 和根目录 `AGENTS.md` 为准。

## 修复

- 已加入同一网络的客户端再次点击“加入网络”时，复用已验证的本机证书、私钥和虚拟 IP，进入原有服务启动流程，不重新登记或消耗邀请次数。
- 协调端拒绝重复节点名（忽略大小写），拒绝可形成路径的节点名。客户端先在临时目录生成 CSR，接入失败不会覆盖已有私钥。
- 发布 LAN 候选地址时排除本机 Meshlink 虚拟 IP，避免为建立底层直连而把握手数据送回尚未连通的虚拟网络。
- 顺序尝试多个 QUIC 候选时，跳过过期地址；存在公网候选时，LAN 阶段最多使用剩余时限的一半，每个 LAN 地址最多尝试 500 毫秒，为公网握手保留时间。

## 验证

- 加入网络回归覆盖身份复用、空邀请重连、重复登记拒绝、失败接入保留私钥。
- 真实 UDP/QUIC 回归在两个无响应 LAN 地址之后提供可达的公网候选，验证身份校验、会话建立和加密数据交付。另覆盖 15 个无响应 LAN 地址和延迟 800 毫秒的公网握手。旧代码及单纯均分时限的方案分别测试失败，最终修复后通过。
- 候选过滤回归使用通配 UDP 监听，确认虚拟 IP 不发布，保留物理 LAN 地址。
- 完整测试和 Windows/Linux 编译通过 `scripts/build.ps1` 执行；实际跨机器 ping/RDP 仍须由 B/C 更新程序后验证。
